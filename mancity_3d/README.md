# 3D로 초고속 정리: 맨시티 115개 혐의 (`mancity_3d.mp4`, 약 2분 11초, 1080p)

맨체스터 시티의 재정 규정 위반 사건을 **빠른 템포의 3D 코미디 애니메이션**으로 풀어 본 영상입니다(2026년 9월 26일 기준).
보도 내용을 바탕으로 한 풍자이고, 영상 끝에 그 사실과 "엠블럼은 패러디 디자인"임을 밝혀 두었습니다.

## 2판에서 바뀐 것

- **템포**: 3분 28초에서 2분 11초로 줄였습니다.
  - 대본을 짧고 강하게 다시 썼습니다.
  - 해설은 빠르고 억양이 큰 목소리(Taek)로 바꾸고, 모든 대사를 1.07배 빠르게 했습니다.
  - 대사 사이 간격은 0.12초로 줄였습니다.
- **훅**: 판결 장면의 **114 : 1** 전광판으로 시작합니다. 이어서 VHS 되감기(◀◀) 효과와 함께 2023년 2월로 돌아갑니다.
- **도파민 효과**:
  - 충격 순간마다 화면 흔들림과 줌 펀치를 넣었습니다.
  - 큰 자막 팝업("쿵!!", "변장 완료!", "수평!", "슝!", "쾅쾅쾅!", "끼익!" 등 14개)이 뜰 때 효과음이 함께 납니다.
  - 속도선을 넣었습니다(파이프 발사·도장 연타·룰렛).
  - 사자 얼굴로 세 번 확대하는 "두둥!" 줌을 넣었습니다.
  - 달력이 넘어가는 동안 "N년 후…" 자막이 나옵니다.
  - 장면 전환은 휩팬(가로로 번지며 밀리는 효과)입니다.
  - 배경음악은 124bpm의 신나는 곡으로 바꿨습니다.
- **겹침 수정**:
  - `render.mjs check`로 0.2초마다 캐릭터끼리, 캐릭터와 소품이 겹치는지 자동으로 검사합니다(캐릭터는 구, 소품은 상자로 봅니다).
  - 다음 겹침을 고쳤습니다: 돈 가방과 시티, 법정의 피고석 상자, 에버튼과 표지판, 문을 뚫고 나오던 시티, 몸에 박힌 봉투, 단상 위 트로피, 저울 접시 위 선수들.
- **엠블럼**: 옷에 구단·리그 배지를 달았습니다.
  - 실제 공식 로고는 저작권·상표권이 있어 쓰지 않았습니다.
  - 대신 색과 형태로 한눈에 알아볼 수 있는 패러디 디자인으로 만들었습니다.
    - 맨시티: 남색·금색 테두리의 원형 "MANCHESTER CITY / MCFC" 배지
    - 에버튼: 파란 방패에 흰 탑과 "EFC"
    - 프리미어리그: 보라색 배지에 초록 왕관과 "PL"
  - 시티, 선수·감독, 접시 위 선수들, 시티 사무실 건물에는 MCFC 배지를 달았습니다. 사자 정장과 법정 벽에는 PL 배지, 에버튼 가슴에는 EFC 배지를 달았습니다.
- **화질**:
  - 캐릭터는 클리어코트 재질로 장난감 같은 광택을 냈고, 볼 터치와 신발 밑창을 넣었습니다.
  - 배경은 그라디언트 하늘에, 바닥은 나무·타일·카펫·잔디·아스팔트 무늬입니다.
  - 벽은 줄무늬 벽지입니다.
  - 소품을 채웠습니다: 화분, 액자, 구름, 덤불, 가로등, 기둥, 전구 달린 룰렛, 스포트라이트.
  - 마지막에 비네트와 필름 그레인을 입혔습니다.

## 사실 관계 (2026.09.26 기준)

- 혐의 내용은 프리미어리그가 2023년 2월 기소하며 제기한 것입니다. 영상에서는 "리그가 본 수법", "~라는 거죠"처럼 리그의 주장으로 설명합니다.
- 115건 중 114건 인정은 9월 25일 BBC·The Athletic 등의 보도입니다.
  - 판결문은 공개되지 않았습니다.
  - 징계는 정해지지 않았습니다.
  - 맨시티는 항소할 방침입니다.
- PSR 손실 한도 £1억 500만/3년, 2020년 UEFA 2년 출전 금지와 CAS의 취소, 에버튼 −10 → −6(항소)은 공개된 사실입니다.
- 실존 인물은 등장시키지 않았습니다. 구단주 쪽 돈은 "구단주 금고"로만 나옵니다.

## 만든 방법

```bash
npm install                      # three, playwright-core
python3 make_assets.py           # 음성·효과음·배경음악(없을 때만 생성) → web/timeline.json, _audio.wav
node render.mjs check            # 캐릭터·소품 겹침 검사
node render.mjs preview DIR 12.5 40 ...   # 원하는 시각의 프레임만 저장
node render.mjs video 3          # 작업자 3개로 렌더링 → mancity_3d.mp4
```

| 파일 | 역할 |
|---|---|
| `story.py` | 대본, 장면별 사건·기준 시각, 큰 자막 팝업(POPS), 대사 속도(TEMPO) |
| `make_assets.py` | 일레븐랩스 생성, 속도 조절(atempo), 타임라인 계산, 효과음 배치, 믹싱 |
| `web/lib.js` | 캐릭터, 패러디 엠블럼, 질감(나무·타일·카펫·잔디·아스팔트·벽지), 소품 |
| `web/app.js` | 장면 10개, 카메라, 충격 흔들림·줌 펀치, 두둥 줌, 속도선, VHS, 휩팬, 자막, 겹침 검사 |
| `render.mjs` | 크로미움(SwiftShader)으로 프레임을 그려 ffmpeg로 인코딩 |
