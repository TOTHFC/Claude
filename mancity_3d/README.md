## 사실 관계 (2026.09.26 기준)

- 혐의 내용은 프리미어리그가 2023년 2월 기소하면서 제기한 것입니다. 영상에서는 "리그는 ~라고 봤습니다"라고 말합니다.
- 115건 중 114건 인정은 9월 25일 BBC·The Athletic 등의 보도입니다.
  - 판결문은 공개되지 않았습니다.
  - 징계는 정해지지 않았습니다.
  - 맨시티는 항소할 방침입니다.
- PSR 손실 한도 £1억 500만/3년, 2020년 UEFA 2년 출전 금지와 CAS의 취소, 에버튼 −10 → −6(항소)은 공개된 사실입니다.
- 구단주·감독 등 실존 인물은 등장시키지 않았습니다. 구단주 쪽 돈은 "구단주 금고"로만 나옵니다.

## 만든 방법

- **3D**: three.js로 장면을 만들고, 헤드리스 크로미움(SwiftShader)에서 한 프레임씩 그립니다.
  - 캐릭터와 소품은 구·캡슐·원기둥 같은 기본 도형을 조합했습니다.
  - 그림자는 소프트 섀도우이고, 조명은 RoomEnvironment 환경광입니다.
  - 입 모양은 대사 음량에 맞춰 움직이고, 눈은 저절로 깜빡입니다.
- **화면 글자**: 자막(화자 이름표), 도장 효과, 누적 막대, 카운터, 전광판, 원형 장면 전환은 2D 캔버스로 겹쳐 그립니다. 글꼴은 Pretendard입니다.
- **소리**: 일레븐랩스로 만들었습니다.
  - 대사는 eleven_v3이고 `[deadpan]`, `[whispers]` 같은 감정 태그를 붙였습니다. 모든 줄을 음성 인식으로 확인했습니다.
  - 효과음 18개를 새로 만들었고, 10개는 `../tottenham_kids`에서 가져왔습니다.
  - 배경음악은 5곡입니다(잠입·뉴스·법정·게임쇼·엔딩).
  - 대사가 나오면 배경음악이 작아집니다.

```bash
npm install                      # three, playwright-core
python3 make_assets.py           # 음성·효과음·배경음악(없을 때만 생성) → web/timeline.json, _audio.wav
node render.mjs preview DIR 12.5 40 ...   # 원하는 시각의 프레임만 저장
node render.mjs video 2          # 작업자 2개로 렌더링 → mancity_3d.mp4
```

| 파일 | 역할 |
|---|---|
| `story.py` | 대본(화자·자막·읽는 소리)과 장면별 사건·기준 시각 |
| `make_assets.py` | 일레븐랩스 생성, 타임라인 계산, 효과음 배치, 믹싱 |
| `web/lib.js` | 캐릭터(시티·사자·부엉이·돈 가방·에버튼·감독)와 소품(저울·서류 더미·트로피·봉투·달팽이 등) |
| `web/app.js` | 장면 9개, 카메라 이동, 자막·도장·카운터 같은 화면 위 글자 |
| `render.mjs` | 크로미움으로 프레임을 그려 ffmpeg로 인코딩 |

음성·효과음·배경음악은 `voice_cache/`, `sfx/`, `bgm/`에 들어 있습니다. 그래서 키 없이도 똑같이 다시 만들 수 있습니다.
