- 인물은 위키미디어 공용(Wikimedia Commons) 사진을 참고해 특징을 과장한 캐리커처입니다. 사진 자체는 영상과 저장소에 넣지 않았습니다.
- 유니폼은 토트넘 2026/27 나이키 홈 킷을 따랐습니다: 흰 바탕, 험멜풍 톤온톤 사선 무늬, 네이비 칼라·소매·옆구리 패널, 빨간 AIA, 네이비 반바지, 흰 양말.
- 등번호는 구단 발표를 따랐습니다: 페르난데스 18, 토날리 16, 갤러거 8, 반 헤케 6, 세네시 5, 아다라비오요 4, 로버트슨 3, 무드릭 27, 반 더 벤 37.
- 글꼴은 Jua, Black Han Sans, Bangers(모두 SIL Open Font License, `fonts/`에 라이선스 포함)이고, 특수기호는 시스템 IPAGothic으로 대체합니다.
- 음악과 효과음은 모두 새로 쓴 멜로디를 신스로 합성했습니다.

## 다시 만들기

```bash
apt-get install -y libegl1 libgl1          # skia 실행에 필요
pip install skia-python numpy imageio-ffmpeg
python3 make_toons.py                      # -> tottenham_toons.mp4
```

- `toon.py`: 드로잉 헬퍼, 텍스트·말풍선(글꼴 폴백), 효과(POW 텍스트, 집중선, 먼지, 아이리스, VHS), 효과음·악기 합성
- `cast.py`: 인물 캐리커처(표정·팔·다리 포즈, 26/27 킷), 마스코트(수탉, 벌, 까치, 나무, 토피, 사자, 망치, 대포, 악마, ENIC 지갑)
- `make_toons.py`: 장면과 타임라인, 렌더링
