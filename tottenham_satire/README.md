# 토트넘 대모험 ~강등권의 전설~

2026년 9월 기준 토트넘 홋스퍼의 현실을 8비트 고전 게임 스타일로 풍자한 패러디 영상입니다.
영상은 `tottenham_adventure.mp4`이고 2분 6초, 1920×1080, 30fps입니다.

## 고증

**26/27 나이키 홈 킷**
- 흰색(릴리화이트) 바탕에 1980년대 험멜 킷에서 따온 은은한 사선 무늬
- 네이비 칼라·소매 끝·옆구리 패널, 네이비 스우시와 엠블럼
- 빨간 AIA 로고
- 네이비(Binary Blue) 반바지, 흰 양말

**등번호 (구단 발표 기준)**
페르난데스 18, 토날리 16, 갤러거 8, 반 헤케 6, 세네시 5, 로버트슨 3, 무드리크 27

**얼굴**
사진을 옮긴 것이 아니라 각 인물의 알려진 특징을 살린 도트 캐리커처입니다.
- 프랑크: 민머리
- 투도르: 짧은 머리, 굳은 표정
- 데 제르비: 곱슬기 있는 검은 머리와 수염
- 토날리: 긴 머리와 수염
- 로버트슨: 붉은빛 수염
- 무드리크: 금발
- 페르난데스: 짧은 곱슬머리

아다라비오요의 등번호는 확인하지 못해 `#?`로 표시했습니다.

- 2025-26 시즌 17위(승점 41). 최종전 에버턴전 1-0 승리로 잔류했고, 웨스트햄이 강등됐습니다.
- 같은 시즌 감독 3명: 프랑크(8경기 무승 끝에 경질), 투도르(44일·7경기 만에 경질), 데 제르비

## 다시 만들기

```bash
pip install pillow numpy imageio-ffmpeg
python3 make_video.py   # -> tottenham_adventure.mp4
```

- `engine.py`: 화면 상수, 한글 도트 텍스트(GNU Unifont), UI, 칩튠 오디오 믹서
- `characters.py`: 인물 초상화·2등신 스프라이트(26/27 킷), 상대팀 마스코트
- `make_video.py`: 장면 구성과 렌더링

테트리스 장면의 배경음은 퍼블릭 도메인인 러시아 민요 「코로베이니키」이고, 나머지 곡은 모두 새로 쓴 멜로디입니다.
