## 다시 만들기

```bash
pip install pillow numpy imageio-ffmpeg
python3 make_video.py   # -> spurs_quest.mp4
```

한글 도트 글꼴로 GNU Unifont(`/usr/share/fonts/opentype/unifont/unifont.otf`)를 사용합니다.
테트리스 장면의 배경음은 퍼블릭 도메인인 러시아 민요 「코로베이니키」이고, 나머지 곡은 모두 이 영상을 위해 새로 쓴 멜로디입니다.
감독 얼굴은 특정인을 묘사하지 않은 범용 도트 아바타입니다.
