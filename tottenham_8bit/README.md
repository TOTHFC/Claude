영상은 `spurs_quest_2627.mp4`이고 2분 55초, 1920×1080, 30fps입니다.

원곡이 퍼블릭 도메인인 미국 전통 가스펠이라 자유롭게 편곡해 썼습니다.

## 다시 만들기

```bash
pip install pillow numpy imageio-ffmpeg
python3 make_8bit.py      # -> spurs_quest_2627.mp4
```

한글 도트 글꼴은 GNU Unifont(`/usr/share/fonts/opentype/unifont/unifont.otf`)를 씁니다.
- `engine.py`: 화면, 텍스트·UI, 칩튠 믹서, 효과음
- `music.py`: Saints 8비트 편곡
- `sprites.py`: 인물 초상화·전신(홈/원정 킷), 마스코트
- `make_8bit.py`: 장면과 렌더링
