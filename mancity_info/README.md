## 디자인

- 1920x1080, 30fps. 남색 배경에 카드형 레이아웃이고, 글꼴은 Pretendard입니다.
- 그래프 색은 어두운 배경에서 색각 이상 검사를 통과한 팔레트만 씁니다.
  - 영입은 파랑, 판매는 빨강입니다.
  - 혐의 범주 다섯 가지는 파랑·주황·초록·노랑·분홍입니다.
  - 시티 하늘색(#6CABDD)은 강조색으로만 씁니다.
- 막대는 끝을 둥글게 한 얇은 막대이고, 축은 하나입니다. 값과 이름은 막대 옆에 바로 적었습니다.
- 내레이션에 맞춰 강조합니다. 이름이 불린 막대만 밝히고, 해당 혐의 범주만 칠합니다.

## 소리

- 내레이션: 일레븐랩스(eleven_v3) 한국어 남성 목소리입니다.
  - 숫자는 한글로 풀어 읽게 했습니다. 예: "0대 3"은 "영 대 삼"으로 읽습니다(`narration.py`의 세 번째 값).
  - 모든 줄을 음성 인식으로 확인했습니다.
- 효과음 7개와 배경음악 2곡: 일레븐랩스 Sound Effects / Music으로 만들었습니다.
  - 혐의 장면에서만 긴장감 있는 곡으로 바뀝니다.
  - 내레이션이 나오면 배경음악이 작아집니다.

## 만들기

```bash
pip install skia-python numpy pillow imageio-ffmpeg
python3 make_info.py                 # -> mancity_info.mp4
python3 make_info.py --preview DIR   # 장면별 대표 프레임만 DIR 에 저장
python3 make_assets.py               # (일레븐랩스 키 필요) 내레이션·효과음·배경음악 새로 만들기 ─ 이미 있으면 건너뜀
```

음성·효과음·배경음악은 `voice_cache/`, `sfx/`, `bgm/`에 들어 있습니다. 그래서 키 없이도 똑같이 다시 만들 수 있습니다.
내레이션 문장을 바꾸면(`narration.py`) 그 줄만 새로 합성합니다.

| 파일 | 역할 |
|---|---|
| `make_info.py` | 장면·그래프·자막·전환, 믹싱, 렌더링 |
| `narration.py` | 내레이션 대본(자막 / 읽는 소리) |
| `make_assets.py` | 일레븐랩스 내레이션·효과음·배경음악 생성 |
