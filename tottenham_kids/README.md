# 힘내요! 데 제르비 (`tottenham_kids.mp4`, 1분 58초)

토트넘의 2026년 9월 상황을 **한국 아동 애니메이션** 형식으로 풍자한 영상입니다.
주인공은 로베르토 데 제르비 감독이고, 짝꿍은 토트넘 수탉 "꼬꼬"입니다.

- **그림**: 2.5등신에 머리가 크고 둥근 캐릭터, 반짝이는 눈, 볼터치, 무지개, 별 모양 화면 전환을 썼습니다.
  얼굴은 위키미디어 공용 사진을 참고해 머리 모양·색, 수염, 피부톤을 살렸습니다.
  - 데 제르비: 삐죽한 검은 머리, 짧은 턱수염, 검은 니트
  - 토날리: 긴 머리와 수염
  - 갤러거: 묶은 금발과 콧수염
  - 토신: 짧은 머리와 수염
  - 손흥민: 앞머리
- **유니폼**: 26/27 홈 킷과 원정 킷(브렌트포드 원정)을 입습니다.
  - 홈: 흰 톤온톤 사선, 네이비 칼라·옆구리 패널, 빨간 AIA
  - 원정: 옵시디언 바탕에 네온 사선, 흰 AIA
- **목소리**: 해설, 데 제르비, 꼬꼬, 어린이들, 케인, 쏘니, 악당, 마을 사람들의 목소리를 모두 음성 합성(edge-tts 한국어)으로 만들었습니다.
  입 모양은 음성 크기에 맞춰 움직입니다.
- **주제가 「힘내요! 데 제르비」**: 작사·작곡을 새로 했습니다.
  - 음악: F장조, 160 BPM. 실로폰, 토이피아노, 베이스, 박수로 반주합니다.
  - 노래: 가사를 단어별로 합성하고 모음 위치를 찾아 음절로 자릅니다. 그다음 PSOLA(Praat)로 음높이를 음표에 고정하고 모음을 늘립니다.
  - 후렴: 남자 목소리를 한 옥타브 아래로 겹칩니다.
  - 화면: 노래방식 가사가 불리는 만큼 색칠됩니다.

```
절)   여기는 토트넘 마을 / 까만 수염 감독님
      패스 패스 또 패스 / 골키퍼까지 돌려요
후렴) 제르비 제르비 데 제르비 / 오늘도 힘을 내요 (힘내요!)
      제르비 제르비 데 제르비 / 강등만은 안 돼요!
```

## 만들기

```bash
pip install skia-python numpy pillow imageio-ffmpeg edge-tts praat-parselmouth scipy
python3 make_kids.py            # -> tottenham_kids.mp4
python3 make_kids.py --preview  # 장면별 대표 프레임만 _preview/ 에 저장
```

음성은 `voice_cache/`에 저장해 두었으므로 네트워크 없이도 똑같이 다시 만들 수 있습니다.
대사를 바꾸면(`script.py`) 그 줄만 새로 합성합니다.

| 파일 | 역할 |
|---|---|
| `make_kids.py` | 장면·자막·전환·배경음악, 렌더링 |
| `kchars.py` | 인물, 꼬꼬, 악당들(벌·까치·나무·에버튼 사탕·사자·망치·붉은 악마), 버스 |
| `kengine.py` | skia 드로잉 헬퍼, 악기·효과음 합성 |
| `ksong.py` | 주제가 작곡·편곡·노래 합성 |
| `voice.py` | 음성 합성 캐시, 단어 타이밍, 음절 분할, PSOLA 노래 |
| `script.py` | 대본 |
