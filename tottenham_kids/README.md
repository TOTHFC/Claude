# 힘내요! 데 제르비 (`tottenham_kids.mp4`, 약 2분 57초, 1080p)

## 소리

- **대사**: 일레븐랩스 한국어 캐릭터 음성입니다(배역은 `eleven_audition.txt`). 대사마다 감정을 붙였습니다.
- **주제가**: Suno로 만든 「힘내요! 데 제르비」(`song/theme_suno.mp3`)입니다.
  - 가사 싱크: 음성 인식 시각이 실제보다 약 1.2초 빨라서 쓰지 않았습니다. 대신 노래에서 **보컬만 분리**(demucs)하고, 음이 시작되는 순간을 음절마다 확인해 `song/theme_suno_lyrics.json`에 저장했습니다.
  - 노래방 자막: 음절을 부르기 시작하는 순간부터 칠합니다.
- **효과음·배경음악**: 일레븐랩스 Sound Effects / Music으로 만들었습니다(`make_sounds.py`, `sfx/`, `bgm/`).
  - 효과음: 뿅, 반짝, 변신, 벌 날갯짓(벌이 보이는 동안 계속), 공 차기, 버스, 까치 날갯짓, 사자, 슬픈 트롬본, 딩동댕, 축포, 귀뚜라미, 호루라기, 장면 전환 등 37개
  - 점수 읽기: 자막은 "0대 3"으로 두고 소리는 "영 대 삼"으로 읽게 했습니다(`script.py`의 `SPOKEN`).
  - 배경음악: 장면별 8곡(마을·경기·연패·퀴즈·화남·밤·교훈·예고)
  - 믹싱: 효과음은 크기를 맞췄습니다. 배경음악은 같은 곡이 이어지는 장면에서 끊기지 않고, 대사가 나올 때 자동으로 작아집니다(더킹).

## 그림

- 2.5등신 캐릭터입니다. 얼굴은 위키미디어 사진을 참고했고, 26/27 홈·원정 킷을 입습니다.
- 캐릭터는 숨을 쉬고, 저절로 눈을 깜빡이고, 말할 때 고개와 손을 움직입니다.
- 장면별 카메라 이동·확대, 번진 그림자·빛·비네트를 넣었고 1920x1080으로 출력합니다.

## 타입캐스트 음성으로 바꾸기

타입캐스트 키가 있으면 대사를 타입캐스트 캐릭터 음성(ssfm-v30, 감정 프리셋)으로 만들고, 없으면 edge-tts로 만듭니다.
키는 채팅에 붙여넣지 말고 클라우드 환경에 등록합니다. 새 세션부터 적용됩니다.

- **API credentials(권장, Pro/Max)**: 이름 `Typecast`, 허용 사이트 `api.typecast.ai`, 헤더 이름 `X-API-KEY`, 접두사(Prefix)는 비우고, 값에 키.
  세션에는 키가 보이지 않고 프록시가 요청에 붙여 줍니다.
- **환경 변수**: `TYPECAST_API_KEY=키`. 그 환경을 쓰는 사람은 값을 볼 수 있습니다.

```bash
python3 audition_typecast.py   # 배역별 후보 목소리를 _audition/ 에 저장하고 발음 인식 결과·음높이 출력
python3 make_kids.py           # 대사를 타입캐스트로 새로 합성해 렌더링(결과는 voice_cache/ 에 저장)
```

## 일레븐랩스 음성으로 바꾸기

일레븐랩스 키가 있으면 일레븐랩스(eleven_v3, [excited]·[sad] 같은 감정 태그)를 먼저 쓰고, 안 되면 타입캐스트, 그다음 edge-tts 순서로 씁니다.

- **API credentials**: 이름 `ElevenLabs`, 허용 사이트 `api.elevenlabs.io`, 헤더 이름 `xi-api-key`, 접두사 비움, 값에 키
- **환경 변수**: `ELEVENLABS_API_KEY=키`

```bash
python3 audition_eleven.py   # 한국어 목소리 라이브러리에서 배역별 후보 오디션 → eleven_voices.json
python3 make_kids.py
```

현재 영상의 대사는 일레븐랩스 음성입니다. 배역은 `eleven_audition.txt`에 있습니다.
해설 Sujin, 데 제르비 Manbo, 꼬꼬 Juwonmom, 어린이들 Chaemong·Hana Lee·JY, 케인 Taemin, 쏘니 Han, 악당 Jang Ho, 마을 사람들 Minjun.

## 만들기

```bash
pip install skia-python numpy pillow imageio-ffmpeg edge-tts praat-parselmouth scipy faster-whisper
python3 make_kids.py            # -> tottenham_kids.mp4
python3 make_kids.py --preview  # 장면별 대표 프레임만 _preview/ 에 저장
python3 make_sounds.py          # (키 필요) 효과음·배경음악 새로 만들기 ─ 이미 있으면 건너뜀
```

음성은 `voice_cache/`에 저장해 두었으므로 네트워크 없이도 똑같이 다시 만들 수 있습니다.
대사를 바꾸면(`script.py`) 그 줄만 새로 합성합니다.

| 파일 | 역할 |
|---|---|
| `make_kids.py` | 장면·자막·전환·배경음악, 렌더링 |
| `kchars.py` | 인물, 꼬꼬, 악당들(벌·까치·나무·에버튼 사탕·사자·망치·붉은 악마), 버스 |
| `kengine.py` | skia 드로잉 헬퍼, 악기·효과음 합성 |
| `voice.py` | 음성 합성(일레븐랩스·타입캐스트·edge-tts)과 캐시, 단어 타이밍 |
| `script.py` | 대본 |
| `make_sounds.py` | 일레븐랩스 효과음·배경음악 생성 |
| `song/` | Suno 주제가와 음절 시각 |
